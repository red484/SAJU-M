계정 및 데이터 삭제

삶의 온기에서 저장한 프로필, 상담, 선택 기록과 저장 답변을 직접 삭제하거나 운영팀에 삭제를 요청할 수 있습니다.

앱에서 바로 삭제하기

  1. 앱을 열고 오른쪽 위의 ‘설정’을 선택합니다.
  2. 화면 아래에서 로그인 상태라면 ‘회원 탈퇴’, 로그인 전이라면 ‘개인정보 전체 삭제’를 선택합니다.
  3. 복구할 수 없다는 확인란을 선택한 뒤 ‘전체 삭제’를 누릅니다.

로그인 없이 이용한 경우 이 방법으로 현재 브라우저 쿠키에 연결된 서버 보관함을 삭제하고 해당 보관함의 연결을 해제합니다. 소셜·토스 또는 아이디로 로그인한 경우에는 같은 위치의 ‘회원 탈퇴’에서 계정과 연결 데이터를 삭제할 수 있습니다.

Apple 로그인 계정

‘전체 삭제’ 확인 뒤 Apple 계정에는 연결 해제 방법을 선택하는 화면이 표시됩니다. ‘Apple 확인 후 탈퇴’를 선택하면 같은 Apple 계정으로 다시 본인을 확인하고, 서버에서 Apple 토큰 철회가 성공한 뒤 서비스 계정과 기록을 삭제합니다. 다른 Apple 계정을 선택하거나 확인·철회에 실패하면 이 경로에서는 서비스 데이터 삭제를 진행하지 않습니다. 다시 설정에서 시도할 수 있습니다.

Apple 확인이 어렵다면 ‘Apple 연결은 직접 해제하고 탈퇴’로 서비스 데이터를 먼저 삭제할 수 있습니다. 이 경우 Apple 연결은 자동으로 해제되지 않으므로 Apple 연결 관리 안내에 따라 직접 해제해 주세요. 내려받은 파일·외부 캘린더 일정은 별도로 삭제해야 합니다.

웹에서 직접 삭제하기

위 직접 삭제 기능은 연령 확인 없이 현재 연결된 데이터에만 적용됩니다. 로그인 연결이 만료됐거나 다른 기기의 계정이라면 아래 고객지원으로 요청해 주세요. 만 14세 이상은 같은 계정으로 웹에 로그인한 뒤 개인 보관함 아래의 ‘회원 탈퇴’에서 직접 삭제할 수 있습니다. 로그인 전에는 ‘개인정보 전체 삭제’로 현재 브라우저의 익명 보관함만 삭제합니다. 이전에 앱에서 로그인 없이 남긴 기록은 다른 브라우저에 자동 연결되지 않습니다.

로그인할 수 없을 때 삭제 요청하기

앱을 삭제했거나 기존 브라우저에 접근할 수 없으면 아래 버튼으로 요청해 주세요. 요청 메일에 사용했던 이름 또는 별명, 이용 시기, 사용 기기 정도를 적어주시면 보유 데이터를 확인하는 데 도움이 됩니다. 타인의 데이터를 지우지 않도록 추가 확인을 요청할 수 있습니다.

구매 정보

탈퇴는 환불 신청을 대신하지 않습니다. 구매 문의가 있으면 주문번호 등 확인 가능한 정보로 환불정책에 따라 접수해 주세요. 토스 주문 정보는 중복 지급을 막기 위해 탈퇴 후에도 계정 연결을 해제한 상태로 남습니다. 주문 정보의 자동 파기는 현재 적용돼 있지 않으며, 거래별 보존 대상·기한·별도 보관 방식은 확인 중입니다. 상담 재시도용 응답 기록은 계정과 함께 삭제됩니다. 자세한 내용은 개인정보처리방침에서 확인할 수 있습니다.

처리 안내

운영팀은 본인 확인 후 합리적인 기간 안에 요청을 처리하고 결과를 회신합니다. 법령상 보존 의무나 보안·분쟁 대응에 필요한 최소 기록은 해당 기간 동안 분리 보관한 뒤 삭제할 수 있습니다.

브라우저 쿠키를 이미 삭제했고 로그인도 사용하지 않았다면, 요청 정보만으로 특정 익명 보관함을 안전하게 식별하지 못할 수 있습니다. 확인되지 않은 다른 이용자의 데이터는 삭제하지 않습니다.
