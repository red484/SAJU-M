계정 및 데이터 삭제

앱에서 바로 삭제하기

  1. 달빛 사주를 열고 오른쪽 위의 ‘보관함 설정’을 선택합니다.
  2. 화면 아래의 ‘개인정보 전체 삭제’를 선택합니다.
  3. 복구할 수 없다는 확인란을 선택한 뒤 ‘전체 삭제’를 누릅니다.

현재 로그인 전 이용자는 이 방법으로 현재 브라우저 쿠키에 연결된 서버 보관함과 기기의 관련 정보를 삭제합니다. 로그인 기능이 활성화된 뒤에는 같은 위치의 ‘회원 탈퇴’에서 계정과 연결 데이터를 삭제할 수 있습니다.

웹에서 삭제 요청하기

앱을 삭제했거나 기존 브라우저에 접근할 수 없으면 아래 버튼으로 요청해 주세요. 요청 메일에 사용했던 이름 또는 별명, 이용 시기, 사용 기기 정도를 적어주시면 보유 데이터를 확인하는 데 도움이 됩니다. 타인의 데이터를 지우지 않도록 추가 확인을 요청할 수 있습니다.

삭제되는 정보

  • 이름 또는 별명과 출생 정보 등 사주 프로필
  • 상담 대화와 저장한 답변
  • 선택 기록, 예상, 회고와 관련 보관함 데이터
  • 로그인 기능 이용 시 계정, 소셜 로그인 연결 정보와 인증 세션

별도로 삭제해야 하는 정보

이용자가 기기에 내려받은 JSON·문서 파일과 캘린더 앱에 가져온 일정은 달빛 사주 서버에서 지울 수 없습니다. 해당 기기와 캘린더 앱에서 직접 삭제해 주세요.

처리 안내

운영팀은 본인 확인 후 합리적인 기간 안에 요청을 처리하고 결과를 회신합니다. 법령상 보존 의무나 보안·분쟁 대응에 필요한 최소 기록은 해당 기간 동안 분리 보관한 뒤 삭제할 수 있습니다.

브라우저 쿠키를 이미 삭제했고 로그인도 사용하지 않았다면, 요청 정보만으로 특정 익명 보관함을 안전하게 식별하지 못할 수 있습니다. 확인되지 않은 다른 이용자의 데이터는 삭제하지 않습니다.
