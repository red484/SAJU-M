# 연령 확인 없는 직접 삭제

2026-11-05. 채널 정책의 공개 삭제 경로를 연령 제한 도입 뒤에도 이용할 수 있도록 보완했다.

`/account-deletion/`은 자바스크립트로 현재 인증 연결만 읽고, 현재 로그인된 계정의 탈퇴 또는 현재 브라우저 쿠키의 익명 보관함 삭제를 제공한다. 새 로그인·가입, 연령 확인용 날짜, 보관함 내용 조회를 요구하지 않는다. 이 페이지에서는 연령 확인값을 발급하거나 상담·기록 저장을 허용하지 않는다. 로그인 불가 시 기존 이메일 문의를 유지하며 실제 메시지는 자동 발송하지 않는다.

- 인증 조회 실패는 익명으로 간주하지 않는다. 삭제 직전 연결된 계정이 바뀌면 중단한다. 만료 계정 보관함에 대한 익명 삭제 시도는 기존 서버 소유권 검증으로 거절한다.
- 복구 불가 확인을 직접 선택해야 요청한다. 실패·취소는 초안·알림·통계 선택을 유지한다. API가 성공을 확인한 경우에만 공통 기기 정리를 실행한다. 초안·이전 로컬 보관함·게스트 모드·통계 선택·현재 기기의 회고 알림 선택을 정리하며 관련 없는 저장소 설정은 유지한다.
- Apple의 기존 `APPLE_REAUTH_REQUIRED` 응답에 따라 자동 재확인 또는 명시적인 수동 연결 해제 후 탈퇴를 선택한다. 자동 재확인 요청은 POST이며 기존 서버 검증을 사용한다. 이 화면에서 시작한 Apple 탈퇴는 공개 삭제 화면으로 돌아와 일회성 완료 확인 후 결과를 표시한다. 허용한 정확한 반환 경로만 사용하며 임의 반환 URL로 보내지 않는다. Apple 계정의 실제 철회를 시험 계정으로 검증한 것은 아니다.
- 자동 탈퇴 후 돌아온 앱에서는 `deletion-result`의 일회성 완료를 확인하고 기기 정리를 한 다음 연령 확인을 표시한다. 임의 URL로 기기 데이터를 지우지 않는다.
- 다른 브라우저의 익명 보관함은 조회·삭제할 수 없다. 인증이 없거나 만료된 계정의 삭제는 소유권 확인을 거친 고객지원 절차가 남는다. 내려받은 파일·외부 일정과 다른 탭·기기의 로컬 정보는 별도다. 실제 토스·네이티브 기기의 인증 전달 및 OS 알림 취소는 이번 검증에 포함하지 않는다.

`tests/direct-deletion.test.mjs`는 명시적 확인·인증 오류·계정 변경·삭제 실패·Apple 선택·성공 후 선택적 기기 정리와 자동 탈퇴의 처리 순서를 검사한다. 기존 서버 인증·CSRF·소유권·Apple 탈퇴 테스트를 함께 실행한다. 보존·백업 설정과 실제 고객 계정은 변경하지 않는다.

로컬 실제 브라우저에서 전용 익명 시험 기록을 만든 뒤 연령 확인값을 제거하고 공개 페이지에서 삭제했다. 확인란 미선택 시 요청 없음, 본문 GET·연령 조회 없음, 서버 보관함 삭제, 관련 기기 설정만 정리됨을 확인했다. 390·768·1440px에서 가로 넘침이 없었다. 실제 고객 계정이나 Apple 계정을 삭제해 시험하지 않았다.
