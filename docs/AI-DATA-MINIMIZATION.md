# AI 외부 전송 최소화

2026년 11월 5일. 계약상 처리 조건 확인과 별개로 소스에서 불필요한 구조화된 전송 항목을 줄였다.

| 항목 | 새 요청의 처리 |
| --- | --- |
| 프로필 이름·별명 | 클라이언트 상담 요청과 서버 모델 문맥에서 제외한다. 이전 클라이언트가 보낸 값도 모델 문맥에 넣지 않는다. 화면의 호칭과 보관함 프로필은 유지한다. |
| 프로필 성별 | 상담 요청·모델 문맥에서 제외한다. 명리 계산은 기존 프로필을 계속 사용하고 이미 계산한 명식·연월 흐름을 상담에 제공한다. |
| 원본 생년월일·도시·이메일 등 임의 프로필 필드 | 상담 서비스는 정해진 명식·자료 필드만 읽는다. 프로필 전체를 임의로 모델에 직렬화하지 않는다. 계산값 자체가 개인정보와 무관하거나 재식별 불가능하다는 의미는 아니다. |
| 선택 기록 ID | 서비스 서버의 자료와 답변 연결에 사용한다. 외부 모델에 전송하는 JSON에서는 제외하며 요청 범위의 `R1` 같은 별칭만 제공한다. |
| 기록과 대화의 내용 | 사용자가 허용·첨부한 제목·날짜·기준·행동·회고·발췌와 현재 대화는 기존 범위에서 처리한다. 모델이 허용된 별칭을 인용했을 때만 서버가 원래 기록 링크를 응답에 붙인다. |
| 판독의 이름 필드 | 사용하지 않는 입력 필드를 제거했다. 계산된 대운 구간·나이 등 판독에 사용하는 값은 유지한다. |

## 범위와 한계

- 적용 지점은 `src/client/app.js`의 상담 명식 구성, `coach-service.mjs`의 허용 필드·모델 문맥·자료 직렬화, `epic-service.mjs`의 입력 판독이다. 재생성·형식 재시도도 같은 모델 문맥을 사용한다.
- 현재 대화·온보딩 고민·허용된 이전 대화와 기록의 자유 입력에 이용자가 개인정보를 적으면 그 내용은 남을 수 있다. 이전에 생성된 답변이 이름을 포함해도 임의로 대화 내용을 편집하지 않는다. 이 처리는 자동 익명화·개인정보 검출 기능이 아니다.
- 계정·보관함 저장 정보와 원래 기록 ID는 서비스 내부에 남는다. 답변 재시도·횟수 차감의 식별자와 참조 연결도 유지한다. 기존에 저장된 답변을 다시 쓰거나 과거 외부 전송 데이터를 소급 삭제하지 않는다.
- Cafe24 Router와 실제 AI 제공자의 처리 국가·보존·학습·위수탁·국외 이전 조건을 확정한 작업이 아니다. 이 수정만으로 관련 고지·계약이 모두 충족됐다고 판단하지 않는다.

## 검증

로컬 응답 대역이 실제 외부 요청 본문을 캡처해 프로필 이름·성별 문맥·내부 기록 ID·임의 식별 필드가 포함되지 않음을 확인한다. 기록의 제목·선택 기준·행동·회고와 명리 계산값은 유지되고, 모델의 `R1` 인용이 응답에서 원래 기록 ID로 연결되는지 확인한다. 클라이언트 명식 구성도 로컬 프로필을 바꾸지 않는지 검사한다. 실제 고객 상담을 새로 전송해 시험하지 않는다.
