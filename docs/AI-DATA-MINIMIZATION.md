# AI 외부 전송 최소화

2026년 11월 5일. 계약상 처리 조건 확인과 별개로 소스에서 불필요한 구조화된 전송 항목을 줄였다.

| 항목 | 새 요청의 처리 |
| --- | --- |
| 프로필 이름·별명 | 클라이언트 상담 요청과 서버 모델 문맥에서 제외한다. 이전 클라이언트가 보낸 값도 모델 문맥에 넣지 않는다. 화면의 호칭과 보관함 프로필은 유지한다. |
| 프로필 성별 | 상담 요청·모델 문맥에서 제외한다. 명리 계산은 기존 프로필을 계속 사용하고 이미 계산한 명식·연월 흐름을 상담에 제공한다. |
| 원본 생년월일·도시·이메일 등 임의 프로필 필드 | 상담 서비스는 정해진 명식·자료 필드만 읽는다. 프로필 전체를 임의로 모델에 직렬화하지 않는다. 계산값 자체가 개인정보와 무관하거나 재식별 불가능하다는 의미는 아니다. |
| 선택 기록 ID | 서비스 서버의 자료와 답변 연결에 사용한다. 외부 모델에 전송하는 JSON에서는 제외하며 요청 범위의 `R1` 같은 별칭만 제공한다. |
| 기록과 대화의 내용 | 사용자가 허용·첨부한 제목·날짜·기준·행동·회고·발췌와 현재 대화는 기존 범위에서 처리하되, 외부 메시지 사본의 흔한 연락처 표기는 아래 후속 처리로 가린다. 모델이 허용된 별칭을 인용했을 때만 서버가 원래 기록 링크를 응답에 붙인다. |
| 판독의 이름 필드 | 사용하지 않는 입력 필드를 제거했다. 계산된 대운 구간·나이 등 판독에 사용하는 값은 유지한다. |

## 범위와 한계

- 적용 지점은 `src/client/app.js`의 상담 명식 구성, `coach-service.mjs`의 허용 필드·모델 문맥·자료 직렬화, `epic-service.mjs`의 입력 판독이다. 재생성·형식 재시도도 같은 모델 문맥을 사용한다.
- 현재 대화·온보딩 고민·허용된 이전 대화와 기록의 자유 입력에 이용자가 개인정보를 적으면 그 내용은 남을 수 있다. 흔한 이메일·휴대전화 표기만 외부 메시지 사본에서 가리며 원본 기록과 이전 답변은 편집하지 않는다. 이름·주소·다른 식별 정보를 포괄적으로 검출하거나 완전히 익명화하는 기능은 아니다.
- 계정·보관함 저장 정보와 원래 기록 ID는 서비스 내부에 남는다. 답변 재시도·횟수 차감의 식별자와 참조 연결도 유지한다. 기존에 저장된 답변을 다시 쓰거나 과거 외부 전송 데이터를 소급 삭제하지 않는다.
- Cafe24 Router와 실제 AI 제공자의 처리 국가·보존·학습·위수탁·국외 이전 조건을 확정한 작업이 아니다. 이 수정만으로 관련 고지·계약이 모두 충족됐다고 판단하지 않는다.

## 검증

로컬 응답 대역이 실제 외부 요청 본문을 캡처해 프로필 이름·성별 문맥·내부 기록 ID·임의 식별 필드가 포함되지 않음을 확인한다. 기록의 제목·선택 기준·행동·회고와 명리 계산값은 유지되고, 모델의 `R1` 인용이 응답에서 원래 기록 ID로 연결되는지 확인한다. 클라이언트 명식 구성도 로컬 프로필을 바꾸지 않는지 검사한다. 실제 고객 상담을 새로 전송해 시험하지 않는다.

## 후속: 흔한 연락처 표기 가림

`ai-contact-redaction.mjs`를 Cafe24 전송 직전의 공통 경로에 적용한다. 현재 대화·이전 답변과 시스템 문맥에 직렬화된 허용 자료 모두에서 일반적인 영문 이메일과 010 / +82 10 휴대전화 표기를 각각 `[이메일 비공개]`, `[휴대전화 비공개]`로 바꾼다. 휴대전화는 가운데·마지막 4자리이며 띄어쓰기·하이픈·점 구분을 지원한다. 키 재시도·이어쓰기·형식 재생성도 매 외부 호출에 적용한다.

원본 메시지를 변경하지 않고 사본을 만들어 전송하며, 원래 연락처·일치 목록·검출 건수를 별도 로그나 DB에 추가하지 않는다. 보관함·인용 링크·차감 식별자·AI 최종 응답은 이 기능에서 고쳐 쓰지 않는다. 인증 헤더·API 키는 가림 대상이 아니다.

연도·날짜·금액·짧은 종목 코드·R1/C1 별칭, 영숫자 ID 내부의 숫자열은 유지한다. 긴 문자열의 부분 일치·반복 탐색을 줄이도록 길이와 문자 경계를 제한했다. 전화번호가 아닌 값이 연락처와 같은 모양이면 가려질 수 있으며, 반대로 유니코드 이메일·다른 전화 접두사·괄호·변형 표기·이름·주소·주민등록번호·계좌번호 등은 놓칠 수 있다. 구분자 없는 숫자열도 연락처와 같으면 가림 대상이다. 완전한 익명화·미전송 보장은 아니며 불필요한 개인정보 입력을 피해야 한다. 가린 표기가 모델 답변에 나타날 수 있다.

`tests/ai-contact-redaction.test.mjs`는 표기별 치환·일반 상담 맥락과 JSON 보존·원본 불변·키 재시도·이어쓰기 요청을 검사한다. 기존 실제 상담 서비스 대역 테스트에서도 첨부 기록의 연락처는 빠지고 인용은 원래 기록으로 연결되는지 확인한다. 실제 고객 상담이나 연락처를 AI 제공자에 새로 전송해 시험하지 않는다. 외부 제공자의 과거 전송본이나 계약 조건은 이번 변경 범위가 아니다.
