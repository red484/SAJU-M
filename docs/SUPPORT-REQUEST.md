# 구매·미성년자 취소 문의 문안

2026년 11월 5일. 고객지원 페이지와 앱 안에서 연 고객지원 문서에서 같은 작성 기능을 사용한다.

## 이용 흐름

1. 문의 유형(환불·미지급/복원·미성년자 구매 취소·중복 결제)과 구매 채널을 선택한다.
2. 결제일·상품명·주문번호·요청 사항은 아는 범위에서 입력한다. 미성년자 유형에서는 구매자 본인·보호자·기타 관계도 선택할 수 있다. 주민등록번호·가족관계증명서·생년월일·상담 내용·비밀번호·결제 인증정보는 이 문안에 요구하지 않는다.
3. 문안을 생성해 확인한 뒤 복사하고, 메일 앱을 열어 본문에 붙여 넣고 발송한다. 메일 링크에는 고정된 문의 제목만 넣고 개인정보나 긴 본문은 URL에 싣지 않는다.
4. 메일 앱·클립보드를 이용할 수 없으면 화면의 문안을 직접 선택·복사해 공개된 고객지원 주소로 보낸다. 작성 내용을 바꾸면 이전 문안을 숨기고 비우며 다시 생성해야 한다. ‘작성 내용 지우기’로 입력과 문안을 초기화할 수 있다.

## 처리 범위

- 서버 접수 API·기기 저장소·분석 이벤트·첨부 업로드·자동 이메일 발송을 추가하지 않는다. 입력은 현재 화면에서만 처리한다. 브라우저 자체의 양식 복원 기능까지 제어하거나 이메일 앱에 복사한 내용을 회수하는 기능은 아니다.
- 작성·복사는 접수가 아니다. 이용자가 이메일을 발송하고 운영팀이 수신한 뒤 문의를 처리한다. 기존 일반 문의 이메일 링크는 항상 제공하며 스크립트가 동작하지 않으면 문안 작성 영역을 표시하지 않는다.
- 미성년자 유형과 관계 선택은 확인 전의 자기 기재다. 법정대리인 동의·본인/보호자 확인·미성년자 결제 권한 검증을 대신하지 않는다. 필요한 추가 확인 항목과 사유는 운영자가 별도로 안내한다.
- 취소 승인·확정 환급액·처리 기한·토스 결제 취소를 실행하거나 약속하지 않는다. 현재 웹은 결제 미리보기이므로 웹 결제 내역 확인 유형에서는 실제 서비스·채널을 다시 확인하도록 안내한다.

## 남은 작업

- 본인·보호자 관계 확인과 미성년자 구매 동의·취소의 실제 운영 기준을 확정하고 적합한 절차를 구현한다.
- 부분 사용·만료·장애·중복 결제 환급 산식과 채널별 처리·증빙을 확정한다.
- 이메일 운영자가 추가 자료를 요청할 때 필요한 최소 범위·안전한 전달 방법·보존 기한을 확인한다. 문안 기능만으로 이를 완료했다고 보지 않는다.

검증: 유형·관계 허용값, 잘못된 날짜·제어문자·길이 제한, 본문이 URL에 포함되지 않음을 자동 테스트한다. 모바일 브라우저에서는 독립 페이지와 앱 문서 창에서 생성·복사/복사 실패 대안·수정 후 초기화·지우기·네트워크 및 기기 저장소에 입력이 실리지 않음을 확인한다. 실제 고객 이메일은 발송하지 않는다.
