# iOS 앱: 삶의 온기

> 과거 노트 전용 iOS 빌드의 기록이다. 새로 등록한 `com.ashwoodfriends.ongi` 앱은
> 사용자 요청에 따라 Android와 같은 전체 서비스를 제공하며, 새 빌드의 기능과 일치하는
> 설명·스크린샷으로 별도 심사받아야 한다. 아래 내용은 기존 빌드에만 해당한다.
> 새 빌드는 iOS 사용자 에이전트의 `OngiFullService/1`로 구분한다. 이전 빌드에는
> 이 표시가 없어 기존 노트 모드가 유지된다. Apple의 이전 4.3(b) 거절은 새 앱에도
> 적용될 수 있으며, 새 이름이나 UI만으로 심사 통과가 보장되지는 않는다.

App Store 심사에서 가이드라인 4.3(b)로 거절됐다. 점성술·운세·사주 앱은 이미 포화된 카테고리라는 사유다.
그래서 iOS 앱은 사주 없이 **선택 기록과 회고**만 제공한다. 서비스명은 Android·웹과 같은 '삶의 온기'를 사용한다.
Android·웹·앱인토스는 기존 사주·상담 기능을 유지한다.

## 동작 방식

iOS 앱도 `capacitor.config.json`의 `server.url`로 운영 웹을 띄운다.
웹 코드가 `Capacitor.getPlatform() === 'ios'`일 때 노트 모드로 동작한다(`src/client/app-mode.js`).

| | 삶의 온기 (Android·웹) | 삶의 온기 (iOS) |
|---|---|---|
| 화면 | 시작·사주 입력·결과·오늘·상담·선택·기록·설정 | 시작·선택·기록·설정 |
| 하단 메뉴 | 오늘·사주·상담·선택·기록 | 새 선택·기록 |
| 기록의 '그날의 해석' | 사주 주제 해석 | 없음 |
| 회고 알림 | 캘린더 파일(.ics) | 기기 로컬 알림(회고일 20:00) + 캘린더 파일 |
| 결제 안내 | 웹만 | 없음 |

- 노트 모드에서 다른 화면으로 가려고 하면(로그인 직후, `?onboarding=1` 등) 기록 화면으로 보낸다.
- 회고 알림은 저장·불러오기 때마다 남은 기록 기준으로 다시 예약한다. iOS 한도 때문에 가까운 60개까지만 예약한다.
- 알림을 누르면 해당 기록이 열린다.
- 알림 권한은 첫 기록을 저장할 때 묻는다.
- 웹에서는 `?app=note`로 같은 화면을 확인할 수 있다. 탭 안에서 유지되며, `?app=saju`로 되돌린다.

**심사 후 서버에서 iOS 앱에 사주 기능을 켜면 안 된다.**
가이드라인 2.3.1(숨겨진 기능) 위반이라 앱이 삭제되고 개발자 계정까지 위험해진다.
iOS의 기능 범위를 바꾸려면 새 빌드로 심사를 받는다.

## App Store Connect 입력안

- 앱 이름: 삶의 온기
- 부제: 선택을 남기고 결과를 돌아보는 노트
- 카테고리: 생산성 (보조: 라이프스타일)
- 키워드: 선택기록,결정일기,회고,다이어리,저널,고민,습관,돌아보기,자기성찰,메모

설명:

> 삶의 온기는 망설이는 선택을 기록하고, 정해 둔 날에 실제 결과를 돌아보는 결정 일기입니다.
> 이직 제안에 답하기, 큰 지출 결정하기처럼 고민되는 선택을 적고, 지금 얼마나 마음이 기울었는지와 예상하는 결과를 남겨 두세요.
> 1일·3일·7일 뒤 돌아볼 날이 되면 알림을 보내 드립니다. 그때 실제 결과와 마음을 적으면 예상과 실제가 나란히 남습니다.
> 기록이 쌓이면 한 달 동안의 선택, 결과, 감정을 모아 보여 주고, 확신이 컸던 선택과 망설였던 선택의 결과를 비교해 나만의 판단 기준을 찾도록 돕습니다.
> 로그인 없이 바로 쓸 수 있고, Apple·Google 계정으로 로그인하면 다른 기기에서도 기록을 이어 볼 수 있습니다. 기록은 언제든 내보내거나 전부 삭제할 수 있습니다.

심사 메모:

> 이전 제출(가이드라인 4.3)을 반영해 앱 콘셉트를 바꿨습니다. 사주·운세·점성술 기능과 문구를 모두 제거했고, 이 앱은 결정 기록과 회고만 제공합니다.
> 첫 화면의 '로그인 없이 이용하기'로 바로 확인할 수 있습니다.
> '새 선택'에서 선택을 기록하면 회고일 저녁 8시에 로컬 알림이 예약되고, '기록'에서 월별 기록과 결과를 남길 수 있습니다.
> 설정에서 내보내기와 계정 및 데이터 전체 삭제가 가능합니다.

스크린샷은 `store-assets/ios-note/`에 있다(6.9인치 1320×2868, 시작·새 선택·기록·기록 상세·월간 돌아보기).
다른 기기 크기는 App Store Connect가 이 규격에서 자동으로 줄여 쓴다.
`?app=note`로 연 웹을 iPhone 크기(440×956, 3배율)로 찍었으므로, 화면이 바뀌면 같은 방식으로 다시 찍는다.
기존 `store-assets/`의 사주 화면 이미지는 iOS에 쓰지 않는다.

개인정보 처리방침(`/privacy/`)·이용약관(`/terms/`)·고객지원·데이터 삭제 안내는 두 앱을 함께 다룬다.
App Store Connect의 개인정보 처리방침 URL은 `https://saju.ashwoodfriends.com/privacy/`를 그대로 쓴다.

## 제출 전 확인

- 운영 서버에 이 버전이 배포되어 있어야 한다. iOS 앱은 운영 웹을 띄우므로, 배포 전 빌드를 심사에 내면 사주 화면이 보인다.
- 실기기에서 첫 기록 저장 → 알림 권한 → 회고일 알림 → 알림 탭 시 기록 열림을 확인한다.
- App Privacy(개인정보 라벨)에서 사주 계산 정보·AI 전송 항목이 노트 앱 기준으로 빠졌는지 확인한다.
