# 만 14세 미만 이용 제한

2026-11-05 운영자 결정에 따라 삶의 온기·달빛 노트 공통으로 만 14세 이상만 이용한다. 보호자 동의를 받아 아동에게 제공하는 경로는 만들지 않는다.

- 로그인·가입·익명 보관함 이용 전에 본인의 **양력** 생년월일을 확인한다. 한국 날짜를 기준으로 14번째 생일 당일부터 허용한다. 클라이언트와 서버가 같은 날짜 검증을 사용한다.
- 확인 날짜는 저장하지 않는다. 서버는 HMAC 서명과 만료 시각만 담긴 확인값을 발급하며 웹은 HttpOnly 보안 쿠키, 토스 등은 탭 세션 저장소·API 헤더로 전달한다. 확인값은 최대 30일, 로그아웃 또는 서버 재시작 후 다시 확인한다. 새 비밀키 설정이나 DB 테이블은 필요하지 않다. 여러 백엔드 프로세스로 확장할 때에는 키 공유 방식을 먼저 설계해야 한다.
- 서버 공통 진입점에서 보관함 읽기·쓰기, 로그인 시작·콜백·게스트/비밀번호 계정·토스 로그인, AI POST, 이용권 지급 요청을 확인값 없이 거절한다. 화면을 제거하거나 기기 시계를 바꾸거나 임의 확인 문자열을 넣는 것만으로 통과할 수 없다.
- 약관·개인정보·환불·고객지원 공개 문서와 건강 상태 조회, 인증 상태, 로그아웃·삭제 요청은 차단하지 않는다. Apple 재확인 후 탈퇴 경로도 유지한다. 연령 확인 화면에서 기존 기록 삭제 문의 안내를 열 수 있다.
- 기존 보관함 읽기와 저장 시 양력·음력(윤달 포함) 프로필을 검증하고 만 14세 미만·잘못된 날짜는 저장 전에 거절한다. 기존 기록을 일괄 삭제하거나 보존 설정을 변경하지 않는다.
- API의 확인 만료 응답은 연령 확인 창을 다시 연다. 기존 입력 화면을 재생성하지 않으며 실패한 상담·결제 요청을 자동으로 재전송하지 않는다.

## 한계와 남은 범위

이는 **자기신고 생년월일 기반 제한**이다. 본인확인 기관·휴대전화·신분증·소셜 계정의 생년월일로 실연령을 인증하지 않으므로 거짓 생년월일까지 탐지하지는 못한다. 만 14세 이상 미성년자의 결제 동의·보호자 확인과 취소 운영은 별개다. 기존 아동 정보 처리 문의는 고객지원에서 접수한다. 보존·백업과 실기기 검증은 이번 작업 범위에서 제외한다.

`npm test`의 연령 경계·위조/만료 확인값·서버 직접 요청·프로필 저장 거부·삭제 경로와 기존 로그인/구매 회귀 테스트로 검증한다.

로컬 실제 브라우저 390·768·1440px에서 입력 차단·성인 진행·확인 창 재진입 시 고민 유지·아동 프로필 차단을 확인했다. 정책 공개 경로와 기존 삭제 API는 연령 확인 없이 접근할 수 있다.
