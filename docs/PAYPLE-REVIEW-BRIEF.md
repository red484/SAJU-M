## 실제 제공 내용

삶의 온기는 **출생 정보로 명식을 계산하고 전통 명리학 해석을 참고하는 생성형 AI 상담 서비스**다. 진로·관계·일상 선택을 대화로 정리하고 선택 기준, 해볼 행동, 회고일을 저장한다. 사용자가 허용하거나 첨부한 과거 대화·선택 기록을 참고할 수 있고, 답변의 명리학 해석 근거와 참고한 기록을 확인할 수 있다.

사람 전문가의 실시간 상담, 진단·치료, 법률 자문이나 투자 수익·미래 결과의 보장을 제공하지 않는다. ‘사주’라는 명칭을 사용하지 않더라도 명리학을 활용하는 실제 기능은 위와 같다.

## 상품과 결제 현황

- 로그인 계정에 정상 AI 답변 누적 5회 무료 제공
- 토스 채널은 1회 결제 상담 50회·구매부터 30일 이용권 구조이며 자동 갱신 없음. SDK가 표시하는 결제창의 최종 가격으로 구매. 안내 기준 가격은 부가세 포함 4,895원
- 무료 횟수 우선 사용, 정상 AI 답변만 차감, 환불 완료 주문의 남은 횟수는 사용 차단
- 웹은 월 4,900원·50회 정기결제 **예정 요금의 미리보기**만 제공. 실제 웹 결제·청구·구독 개시 기능 없음
- 페이플 결제창·승인·웹훅·환불 연동은 아직 없음. 웹 상품의 최종 계약 조건도 확정 전
- iOS 달빛 노트는 선택 기록·회고용 별도 앱이며 명리 계산·AI 상담·이용권 구매 없음

1. 위 명리학 활용 기능이 페이플의 가입 불가 업종 ‘사주/운세 서비스’에 해당하는지 판단 요청. 명칭 변경만으로 심사 가능하다고 전제하지 않는다.
2. 현재 기능 그대로 입점 심사가 가능한 경우 필요한 상품 분류와 추가 자료 확인.
