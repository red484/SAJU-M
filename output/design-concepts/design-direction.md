## 공통 생성 프롬프트

Use case: ui-mockup. Create a polished high fidelity mobile UI redesign presentation for an existing Korean app named exactly "삶의 온기". This is a saju-informed life counseling and decision journal app, core promise: help organize current concerns, make a choice, record and later reflect. This is a design proposal, not marketing website. Landscape image, 3 tall complete mobile app screen canvases side by side, equal size, thin subtle frame, no physical phone hardware, no perspective, no cropped screens. Each screen 390x844 logical proportion with generous 20px side padding. Tiny understated Korean screen labels above each. Neutral pale gray surrounding board. Pixel-sharp realistic UI, readable correct Korean typography. Consistent restrained editorial design: paper-white #FAFAF7, white surfaces, near-black ink #272B28, muted gray #69716B, deep tea green #39594D used sparingly, soft sage neutral panels. MaruBuri-like Korean serif for short emotional headlines, clean Korean sans for all labels/body. One small abstract circle-and-branch brand mark. Thin gray borders, controlled 12-18px corner radius, 48px controls, ample spacing, clear hierarchy. Mostly flat surfaces, no gradients, no glass, no big shadows, no brown/green legacy mixture, no emoji, no generic rainbow tiles, no decorative backgrounds behind text. An evocative monochrome ink botanical illustration may appear on welcome only. Korean interface text should be carefully typeset and legible. All people, birth details and counseling messages are illustrative sample data.

## 화면별 지시

첫 이미지: 시작 화면의 고민 입력과 로그인, 출생 정보 프로필 폼, 진로 상담 대화와 해석 근거·저장 기능을 세 개의 완전한 모바일 화면으로 구성.

두 번째 이미지: 상담에서 추출한 선택 기준 세 가지, 선택 이유와 마음 및 회고 날짜를 입력하는 폼, 2026년 11월 달력과 두 건의 선택 기록을 세 개의 완전한 모바일 화면으로 구성. 첫 이미지와 같은 타이포그래피·색상·탭 바 사용.
