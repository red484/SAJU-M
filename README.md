# 달빛 사주 v3

달빛 산수화 첫 화면을 유지하고, 결과·체험 코칭·선택 기록을 확장한 서버 기반 웹사이트입니다.

## 실행

Node.js 22 이상, npm을 사용합니다.

```sh
npm ci
npm run build
npx wrangler d1 migrations apply dalbit-local --local
npm run dev
```

미리보기: http://localhost:8766

```sh
npm test
node tests/storage.test.mjs
```

저장 테스트는 로컬 서버 실행 중에만 수행하며 별도 세션에 테스트 기록을 생성하고 지웁니다.

## 구현한 기능

- 한국 음력·윤달 변환, 절기 시각 기준 년·월주, 현지 시간대, 선택적 지방평균태양시, 시간 미상 안내
- 핵심 요약·강점·주의점·관심 주제별 해석·오늘의 행동·해석 근거 펼치기
- 대화 문맥과 사주 프로필을 반영하는 규칙 기반 체험 코칭, 이전 대화, 복사·저장·공유
- 서버 저장, 세션별 데이터 분리, 충돌 감지, 개인정보 전체 삭제, JSON·텍스트 내보내기
- 선택 기록 상세·수정·삭제, 예상과 실제 회고, 월간 달력·감정·확신별 요약
- 1·3·7일 후 회고 캘린더 파일 (가져오기를 완료해야 일정·알림이 등록됨)
- 모바일 화면 및 데스크톱 결과/상담 2열

## 명확한 범위

실제 AI·자동 푸시·이메일·결제는 연결하지 않았습니다. 상담은 규칙 기반입니다.
서버 보관함은 HttpOnly 쿠키로 연결하며 기기 간 계정 동기화·복구를 지원하지 않습니다.
쿠키를 삭제하기 전에 필요한 데이터를 내보내야 합니다. 서버 운영자가 접근할 수 없는 종단간 암호화는 아닙니다.

사주 해석은 자기 이해용 전통 해석으로 미래나 성격의 과학적 진단이 아닙니다.
오행 비율은 대표 오행 개수이며 용신·신강/신약 판정이 아닙니다. 년·월주는 실제 시각을 UTC+8 계산표로 비교하고, 일·시주는 선택한 현지 시각 또는 경도 보정 시각을 사용합니다. 자정 일주 교체를 채택합니다. 지방평균태양시는 균시차까지 반영한 진태양시가 아닙니다. 서머타임 중복 시각은 모호하게 추정하지 않고 입력 오류로 표시합니다.

## 게시 상태

기존 Sites 프로젝트 ID는 `.openai/hosting.json`에 유지되어 있습니다. 현재 연결 계정에서 기존 사이트를 찾지 못해 v3는 아직 게시되지 않았습니다. 원래 Sites 계정으로 연결한 뒤 동일 프로젝트에 게시해야 합니다. 새 사이트를 임의로 생성하지 않았습니다.

이미지는 개별 WebP로 제공하며 초기 HTML에 삽입하지 않습니다. 소스의 generated-assets.js는 빌드 시 Worker용 배포 호환 자산으로 생성되며 브라우저 HTML에 포함되지 않습니다.
